# Getting Started

API Workbench is a developer tool for testing, benchmarking, and mocking HTTP APIs directly in your browser.

---

## Core Tools

- **API Tester**: Send single HTTP requests or run automated benchmarks with latency and status metrics.
- **Mock APIs**: Create simulated HTTP endpoints with custom status codes, headers, and JSON responses.
- **My APIs**: Save requests and organize them into workspaces for quick access.
- **Settings**: Manage profile details, change passwords, and manage your account.

---

## Quick Start

1. **Sign Up**: Create an account with your name, username, email, and password, then enter the 6-digit email verification code.
2. **Send a Request**: Open the **API Tester**, choose an HTTP method, enter a URL, and click **Send**. Inspect the response in **Pretty**, **Raw**, or **Headers** view.
3. **Save an API**: In the response panel, click **Save API**, choose a workspace, and save the request.
4. **Create a Mock**: In **Mock APIs**, click **+ New Mock**, set the method, path, status code, and JSON body, then click **Save Mock**. Click **Test** to run it in the tester.
